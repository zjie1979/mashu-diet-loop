# 麻薯小狗

公开静态 PWA。用于在 iPhone Safari 打开并添加到主屏幕。

- 三页式结构：首页打卡、餐单库、记录统计。
- 数据只保存在当前浏览器的 localStorage。
- 根据用户提供的小红书主页和已登录后可读的“麻薯小狗泥”公开笔记正文整理，非官方授权版。
- 每天从全部餐单里自己选定一份餐单打卡，不自动循环。
- 餐单库按系列进入，再查看每天可选餐单和详情。
- 记录页显示每份餐单累计打卡次数。
- 已按需求过滤调酒、甜品、纯 tips 和单品推荐；含汤内容按少汤热菜/配菜口径整理。
- 当前收录 27 个可打卡日，覆盖食欲稳定结构、节后恢复三日、大餐后恢复、白日液断、小基数七日、基础三餐和懒人带饭。
- 不包含账号、服务端、私密数据或第三方接口。
- 餐单包含短期恢复、液断和小基数较激烈食谱，不建议长期连续执行。
